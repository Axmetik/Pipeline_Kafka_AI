|---|---|---|

| hybrid false 13:30,13:40,13:50,14:00 | Підтверджено всі чотири | **Поінтервальної історії hybrid немає.** Журнал показує два розділені епізоди, але не кожне false-рішення. |
| high/hybrid true з14:10 під час втручання | Підтверджено | Початок другого hybrid-епізоду14:10 і походження за весь епізод; історії high-рішень немає. |
| Hybrid епізоди13:20—13:20 та14:10—15:20 | Підтверджено | Межі, 1/8 точок, closed/negative відображено правильно; це **два**, а не один епізод. |
| Закриття на вимірюваннях13:30 і15:30 | Підтверджено в етапі3 з наступних рішень і persisted updated_at | **Окремі часові мітки закривальних вимірювань не показано.** UI «останній сигнал» = остання true, не close time. |

Фінальні картки «0 відкритих», «відхилення немає», scores нижче порогу стосуються кінця потоку, **не відсутності історичних реакцій**. Саме тому поряд знімали історичні графіки й журнал.
